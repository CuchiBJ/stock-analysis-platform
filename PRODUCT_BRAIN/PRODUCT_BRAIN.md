This is the **PRODUCT BRAIN** - a living documentation system that:
- Serves as the single source of truth for all product decisions

- Guides LLM interactions to maintain coherence
- Preserves operational philosophy over time
- Maintains visual and UX consistency

## CORE PHILOSOPHY

**This product is an INSTITUTIONAL MOMENTUM OPERATING SYSTEM**

Not a screener. Not a dashboard. Not a SaaS platform.

It is an **operating system** for:
- Swing momentum trading
- Continuation setup detection
- Institutional sponsorship tracking
- Setup lifecycle analysis
- Regime-aware decision making
- Contextual compression

---

## NON-NEGOTIABLE PRINCIPLES

1. **Transitions > Static States**: The system focuses on changes, not snapshots
2. **Context > Scores**: Raw metrics without context are noise
3. **Deterioration Matters**: Decay is as important as growth
4. **Scarcity is Signal**: Quality setups are rare by design
5. **Quality > Quantity**: Fewer, better setups over more noise
6. **Clarity > Complexity**: Every element must earn its place
7. **Workflow > Analytics**: Operational speed beats feature count
8. **Regime Affects Everything**: Market context changes all rules

## VERSIONING PHILOSOPHY

This documentation uses **conceptual versioning**, not semantic versioning.

Versions track **philosophy changes**, not implementation details.

Format: `v{major}.{minor}.{philosophy}`

- **major**: Philosophy shift (rare, requires consensus)
- **minor**: New principle or rule addition
- **philosophy**: Clarification, examples, refinement
